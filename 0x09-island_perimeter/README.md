# Island Perimeter Project

# Description

- This project implements a function that calculates the perimeter of an island represented by a 2D grid. The grid consists of 0s and 1s:

0 represents water.

1 represents land.

- The task is to determine the perimeter of the island. The grid is completely surrounded by water, and there is only one island (or none). The island is connected either horizontally or vertically (not diagonally).
